# Fairbook

Clear markets. Quiet desk.

A frontend-only market terminal with live crypto and stock updates, TradingView-style candlestick charts, watchlists, and paper trading. No backend.

## Full documentation

For a **first-principles guide** (zero trading knowledge): what the app does, why each feature exists, and how it works — see:

**[docs/COMPLETE_GUIDE.md](./docs/COMPLETE_GUIDE.md)**

## Stack

- Vite + React + TypeScript
- Lightweight Charts
- CoinGecko (crypto) + Fin-node (stocks)
- Zustand + TanStack Query

## Run

```bash
npm install
npm run dev
```

## Note

Paper trading only. Not financial advice. Market data comes from free public APIs and may be delayed or rate-limited.
